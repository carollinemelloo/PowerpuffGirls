# Powerpuff Girls Shooter 🎮

Um jogo 2D desenvolvido em **Python** utilizando a biblioteca **Pygame**. O jogador controla uma das Meninas Superpoderosas, navega pelo mapa, derrota inimigos e enfrenta o Macaco Louco em uma batalha final.

## 🚀 Requisitos

Certifique-se de ter o Python instalado. Você precisará instalar a biblioteca `pygame` via terminal:

```bash
pip install pygame

## 📂 Estrutura do Projeto
O código depende de uma pasta chamada assets no mesmo diretório do script principal contendo as imagens necessárias. Certifique-se de que a estrutura esteja organizada assim:

/seu-projeto
│
├── main.py
└── /assets
    ├── florzinha.png
    ├── lindinha.png
    ├── docinho.png
    ├── professor.png
    ├── ele.png
    └── macacolouco.png
Nota: Se os arquivos de imagem não estiverem presentes na pasta assets, o jogo encerrará automaticamente ao iniciar.

## 🎮 Controles
Ação	Tecla
Movimentação	W, A, S, D
Atirar	Espaço
Rotação	Q (Anti-horário) / E (Horário)
Escala (Tamanho)	Z (Aumenta) / X (Diminui)
Espelhar Personagem	F
Reiniciar Jogo	R
Seleção Inicial	1, 2, 3

## 🕹️ Como Jogar
Seleção: Ao iniciar, pressione 1, 2 ou 3 para escolher sua personagem.

Fase 1: Explore o mapa, derrote os inimigos e chegue até o Professor para avançar de fase.

Fase 2 (Chefe): Enfrente o Macaco Louco. Desvie dos projéteis e atire para reduzir a vida dele.

Objetivo: Sobreviva aos ataques e derrote o chefe para vencer o jogo!

## 🛠️ Tecnologias Utilizadas
Python

Pygame: Utilizado para renderização gráfica, controle de eventos, colisões e gerenciamento de estados de jogo.
